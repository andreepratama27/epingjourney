## 1. Voice & Tone — "Hangat, Dekat, Bukan Klinis"

EpingJourney bicara seperti **teman sesama Bunda yang sudah lebih dulu lewat fase eping** —
bukan dokter, bukan brand korporat, bukan aplikasi medis.

```
╭──────────────────────────────────────────────────────────────╮
│              SPEKTRUM TONE BAHASA INDONESIA                  │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  Sangat Formal       ←   KITA DI SINI   →     Sangat Casual  │
│                                                              │
│  Anda · Saudari   Kamu · Bunda          Lo · Gue · Bre       │
│  "Mohon untuk"    "Yuk, kita..."        "Cobain dong"        │
│  "Silakan"        "Coba dulu"           "Gas aja"            │
│                                                              │
│  ✗ Terlalu jauh   ✓ Hangat & dekat       ✗ Terlalu santai    │
│  ✗ Klinis         ✓ Sopan tapi akrab     ✗ Tidak universal   │
│                                                              │
╰──────────────────────────────────────────────────────────────╯
```

### Prinsip Utama
1. **Sapa sebagai "Bunda"** untuk momen hangat (hero, CTA, empati). Gunakan "Kamu" untuk
   instruksi netral (form, tooltip, error). Hindari "Anda" — terlalu kaku.
2. **Boleh pakai bentuk pendek** (`nggak`, `udah`, `gimana`) di copy yang meniru pikiran
   pengguna (mis. testimoni, bagian "Problem"). Tetap pakai bentuk baku (`tidak`, `sudah`,
   `bagaimana`) di tombol, navigasi, dan pesan sistem.
3. **Empati dulu, fitur kemudian.** Setiap blok copy dibuka dengan validasi perasaan,
   baru solusi.
4. **Pendek dan ramah.** Kalimat ≤ 12 kata bila memungkinkan. Bunda baca ini jam 3 pagi.
5. **Hindari istilah medis berat.** "ASI perah" lebih hangat dari "ASIP terkumpul";
   "pumping" sudah lazim, biarkan apa adanya.

### Kata yang Dihindari
| ❌ Hindari            | ✅ Pakai                         | Alasan                          |
|----------------------|----------------------------------|---------------------------------|
| Anda                 | Kamu / Bunda                     | Terlalu formal, terasa jauh     |
| Pengguna             | Bunda                            | "Pengguna" mengeringkan suasana |
| Sesi laktasi         | Sesi pumping                     | Bunda sehari-hari pakai ini     |
| Volume produksi      | Hasil perah / hasil pumping      | Lebih natural                   |
| Mohon menunggu       | Tunggu sebentar ya               | Lebih hangat                    |
| Berhasil             | Selesai · Tercatat · Mantap      | Variasi yang lebih hidup        |
| Gagal / Error        | Belum berhasil · Yuk coba lagi   | Tidak menghakimi                |

## 5. Struktur Teknis i18n

Walaupun MVP menggunakan Bahasa Indonesia saja, struktur kode harus sudah
i18n-ready sejak hari pertama. Tidak ada string yang di-hardcode di komponen.

```
src/
├── i18n/
│   ├── index.ts              # init + locale detection
│   ├── locales/
│   │   ├── id.json           # ← default, satu-satunya yang diisi di MVP
│   │   ├── en.json           # placeholder, mirror dari id.json
│   │   └── ms.json           # placeholder, mirror dari id.json
│   └── types.ts              # generated key types untuk type-safety
└── components/
    └── (pakai t('hero.cta') bukan string literal)
```

### Konvensi Penamaan Key

```
<section>.<element>.<variant?>

contoh:
  hero.headline
  hero.cta.primary
  hero.cta.hint
  problem.h2
  problem.card.timeAgo
  feature1.title
  feature1.bullets.0
  feature1.bullets.1
  scheduler.status.completed
  scheduler.status.overdue
  scheduler.status.upcoming
  cta.final.headline
  microcopy.loading
  microcopy.save.success
  microcopy.save.failed
  glossary.eping
  glossary.session
```

### Library yang Direkomendasikan

- **`@lingui/react`** atau **`react-i18next`** untuk runtime translation.
- **`i18next-browser-languagedetector`** untuk auto-detect dari browser.
- **Default fallback:** `id` (bukan `en` — kita Indonesia first).
- Toggle bahasa **disembunyikan di MVP**, tapi infrastrukturnya sudah ada.

### Number, Date, & Unit Formatting

```
Konteks            │  Indonesia            │  Catatan
───────────────────┼───────────────────────┼─────────────────────────
Volume oz          │  3,5 oz               │  koma sebagai desimal
Volume ml          │  120 ml               │
Tanggal            │  30 Apr 2026          │  format pendek
Hari               │  Senin · Sel · Rab    │  singkat 3 huruf
Waktu              │  06:00 · 14:30        │  24-jam, bukan AM/PM
Durasi             │  14 mnt 23 dtk        │  pakai mnt/dtk
Rating             │  4,9 / 5              │  koma desimal
Jumlah Bunda       │  1.200+               │  titik sebagai ribuan
```

Pakai `Intl.NumberFormat('id-ID')` dan `Intl.DateTimeFormat('id-ID')` —
jangan format manual.


### Catatan Pertimbangan untuk Bahasa Melayu (ms-MY)

Banyak istilah Eping di Indonesia (mis. "pumping") sama persis di Malaysia.
Tapi beberapa berbeda — *file `ms.json` BUKAN copy-paste dari `id.json`*:

```
EN              │  ID (kita)             │  MS (nanti)
────────────────┼────────────────────────┼─────────────────────
Mom             │  Bunda                 │  Ibu / Mama
Pump            │  Pumping               │  Memerah / Pumping
Schedule        │  Jadwal                │  Jadual (ejaan beda)
Today           │  Hari Ini              │  Hari Ini (sama)
Save            │  Simpan                │  Simpan (sama)
Free            │  Gratis                │  Percuma
```

Saat fase ms-MY dimulai, libatkan native speaker Malaysia untuk review —
jangan asumsi mirip Indonesia.

### Catatan untuk English (en)

- Voice setara: warm, mom-to-mom, bukan korporat. Patuhi tone PRD asli.
- Konversi unit: tetap default oz, tapi tawarkan ml di setting.
- Format tanggal: `Apr 30, 2026` untuk en-US; `30 Apr 2026` untuk en-GB.

## 7. Checklist QA Bahasa (Sebelum Rilis)

- [ ] Semua tombol & label sudah konsisten pakai sapa "Bunda" atau "Kamu",
      tidak ada "Anda" tersisa.
- [ ] Tidak ada string hardcoded di komponen — semua via `t('...')`.
- [ ] Format angka pakai koma desimal (3,5 oz bukan 3.5 oz).
- [ ] Format tanggal pakai locale `id-ID`.
- [ ] Empty state, error, dan loading semua punya copy yang hangat.
- [ ] Tone bagian Problem & testimoni terasa natural (boleh pakai `nggak`,
      `udah`), tone bagian sistem & form tetap baku.
- [ ] Tidak ada istilah medis kaku ("volume produksi", "sesi laktasi").
- [ ] Cek panjang teks Bahasa Indonesia di tombol — biasanya lebih panjang
      ~20% dari Inggris; pastikan tidak overflow di mobile.

## 8. Open Questions

1. Apakah perlu opsi **"Mama" / "Mom" / "Ibu"** sebagai alternatif sapa
   "Bunda" di setting? (Beberapa Bunda nggak pakai sebutan itu.)
2. Apakah copy boleh menyebut **suami / pasangan** (mis. di reminder)?
   Atau netral saja untuk inklusivitas (single mom, same-sex couple)?
3. Untuk pasar Malaysia nanti — **ejaan campuran** (mis. "Jadual" vs
   "Jadwal") boleh muncul di marketing yang lebih luas, atau strict per
   locale?
4. Kapan toggle bahasa muncul di UI? Di v2.0 saat ada locale kedua, atau
   selalu disembunyikan dan auto-detect saja?
